콘솔창 계산기 프로그램

Windows OS의 경우

1. F12 키를 눌러 콘솔 창을 여세요.

2. start() 를 콘솔창에 입력하여 계산기를 실행합니다.

Mac OS의 경우

1. Option + Command + I 키를 눌러 콘솔 창을 여세요.

2. start() 를 콘솔창에 입력하여 계산기를 실행합니다.

지원 기능

  • 사칙연산 + - * / 및 소수점, 음수(3 * -2)
  • 긴 계산식 (예: 1 + 2 + 3 * 5 + 6 / 3)
  • 연산자 우선순위: *, / 를 먼저 계산
  • 잘못된 입력·0으로 나누기 오류 안내
