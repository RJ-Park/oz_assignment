# HTML / CSS 1일차 핵심 태그 정리 (`tag.md`)

## 1. HTML 문서 기본 구조 태그
| 태그 | 설명 및 역할 | 기본 사용 예시 |
| :--- | :--- | :--- |
| `<!DOCTYPE html>` | 현재 문서가 **HTML5 표준 문서**임을 웹 브라우저에 알리는 선언문. 문서 최상단에 작성. | `<!DOCTYPE html>` |
| `<html>` | HTML 문서의 **최상위(루트) 요소**로, 문서 내의 모든 태그를 감쌈. `lang` 속성으로 주 사용 언어 코드 기재. | `<html lang="ko"> ... </html>` |
| `<head>` | 브라우저 화면에 직접 보이지 않지만 문서의 **설정 및 부가 정보(메타데이터)**를 담는 영역. 문자 인코딩(`<meta>`), 브라우저 탭 제목(`<title>`), 외부 CSS 파일 연결(`<link>`) 등을 포함. | `<head><meta charset="UTF-8"><title>제목</title></head>` |
| `<title>` | `<head>` 내부에 위치하며, **브라우저 탭 제목** 및 검색 엔진 결과 제목으로 표시. | `<title>Resume</title>` |
| `<body>` | 브라우저 **화면에 실제로 출력되는 모든 본문 콘텐츠**(텍스트, 이미지, 표, 입력 폼 등)가 위치하는 영역. | `<body><h1>안녕하세요</h1></body>` |

## 2. 텍스트, 제목 및 구분선 태그

문서 내 글의 위계(계층)를 잡거나 문단과 줄바꿈, 구분선을 표현할 때 사용.

* **`<h1>` ~ `<h6>` (Heading)**: 제목을 나타내는 태그. `<h1>`이 가장 크고 중요한 대제목이며, 숫자가 커질수록(`<h2>` → `<h6>`) 글자 크기와 중요도가 낮아짐.
  ```html
  <h1>박유정 이력서</h1>
  <h2>자기소개</h2>
  <h3>보유 기술</h3>
  ```
* **`<p>` (Paragraph)**: 하나의 **문단(단락)**을 정의할 때 사용. 블록 레벨 요소이므로 문단 위아래에 자동으로 기본 여백이 생성.
  ```html
  <p>HTML: 웹 페이지의 구조를 정의하는 마크업 언어.</p>
  ```
* **`<br>` (Line Break)**: 문단(`<p>`) 내부에서 새로운 문단을 만들지 않고 **줄바꿈**만 수행할 때 사용하는 빈 태그(닫는 태그 없음).
  ```html
  안녕하세요!<br> 웹서비스 학습자입니다.
  ```
* **`<hr>` (Horizontal Rule)**: 주제가 전환되거나 섹션을 시각적으로 분리할 때 **가로 수평선(구분선)**을 긋는 빈 태그.
  ```html
  <section>자기소개 영역</section>
  <hr>
  <section>이력 영역</section>
  ```
* **`<strong>` / `<em>`**: 문장 내 특정 텍스트를 굵게 강조(`<strong>`)하거나 기울임꼴로 강조(`<em>`)할 때 사용하는 인라인 태그.

## 3. 목록(List) 태그

기술 스택, 프로젝트 이력, 네비게이션 메뉴 등 여러 항목을 나열할 때 사용.

* **`<ul>` (Unordered List)**: **순서가 없는 목록**을 만듭니다. 각 항목 앞에 불릿(•) 기호 붙임.
* **`<ol>` (Ordered List)**: **순서가 있는 목록** 생성. `type` 속성(`"1"`, `"A"`, `"a"`, `"I"`, `"i"`)을 사용해 숫자나 로마자 등으로 번호 스타일 지정 가능.
* **`<li>` (List Item)**: `<ul>` 또는 `<ol>` 내부에서 **개별 목록 항목 하나하나**를 감싸는 태그.

```html
<!-- 순서 없는 목록 (ul) -->
<ul>
    <li>Python</li>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<!-- 순서 있는 목록 (ol) -->
<ol type="i">
    <li>기초 문법 복습</li>
    <li>이력서 페이지 구현</li>
    <li>GitHub 업로드</li>
</ol>
```

## 4. 표(Table) 태그

학력, 경력, 교육 이력처럼 행(Row)과 열(Column)로 이루어진 정형 데이터를 표 형태로 정리할 때 사용.

| 태그 | 설명 및 역할 |
| :--- | :--- |
| `<table>` | 표 전체를 감싸는 최상위 컨테이너 태그 (`border="1"` 속성으로 기본 테두리 확인 가능). |
| `<thead>` | 표의 **머리글(컬럼 제목) 행**들을 묶어주는 영역. |
| `<tbody>` | 표의 **실제 본문 데이터 행**들을 묶어주는 영역입니다. |
| `<tr>` | **Table Row**의 약자로, 표 내부의 **가로 한 줄(행)**을 정의함. |
| `<th>` | **Table Heading**의 약자로, 표의 **제목 셀** 생성 (기본값: 굵은 글씨 + 가운데 정렬). |
| `<td>` | **Table Data**의 약자로, 표의 **일반 데이터 셀** 생성 (기본값: 일반 글씨 + 왼쪽 정렬). |

```html
<table border="1">
    <thead>
        <tr>
            <th>기간</th>
            <th>과정명</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>2026.10 ~ 현재</td>
            <td>OZ코딩스쿨 AI 헬스케어 초격차 캠프</td>
        </tr>
    </tbody>
</table>
```

## 5. 미디어 및 하이퍼링크 태그

프로필 사진을 넣거나 외부 웹 페이지(GitHub 레포지토리 등)로 연결시 사용.

* **`<img>` (Image)**: 웹 페이지에 이미지를 삽입하는 빈 태그.
  * `src` (source): 불러올 이미지 파일의 경로(상대 경로/절대 경로) 또는 웹 URL 지정.
  * `alt` (alternative text): 이미지를 불러올 수 없을 때 대신 화면에 표시할 **대체 텍스트**이며, 스크린 리더 등 웹 접근성을 위해 작성 필수.
  ```html
  <img src="./surfingcat.webp" alt="프로필 이미지">
  ```
* **`<a>` (Anchor)**: 다른 웹 페이지, 파일 또는 같은 페이지 내 특정 위치로 이동하는 **하이퍼링크** 생성.
  * `href` (hypertext reference): 이동할 대상 URL 또는 파일 경로 지정.
  * `target="_blank"`: 링크 클릭 시 새 탭에서 페이지 열기 실행.
  ```html
  <a href="https://github.com/RJ-Park" target="_blank">GitHub 보러가기</a>
  ```

## 6. 사용자 입력 및 폼(Form) 태그

로그인, 검색, 회원가입, 이력서 하단 메일 발송 양식처럼 사용자로부터 데이터를 입력받아 서버로 전송할 때 사용.

* **`<form>`**: 입력 양식 전체를 감싸는 태그
  * `action`: 입력 데이터를 전송받아 처리할 서버의 URL 주소
  * `method`: 전송 방식 지정 (`get`: URL 쿼리 스트링에 데이터를 노출하여 조회/검색 시 사용, `post`: HTTP 본문에 데이터를 숨겨 전송하여 회원가입/메일 발송 등에 사용)
* **`<label>`**: 입력창(`<input>`)의 이름표를 표시. `<label for="아이디">`와 `<input id="아이디">`를 일치시키면 라벨 텍스트를 클릭했을 때도 해당 입력창으로 포커스 이동.
* **`<input>`**: 사용자로부터 다양한 형태의 값을 입력받는 빈 태그.
  * 주요 `type` 속성:
    * `type="text"`: 일반 한 줄 텍스트 입력
    * `type="email"`: 이메일 형식(`@` 포함 여부 등) 자동 검증
    * `type="password"`: 입력 문자를 마스킹(`••••`) 처리
    * `type="search"`: 검색어 입력창
  * 주요 부가 속성:
    * `name`: 서버로 데이터가 전송될 때 사용되는 키(Key) 이름
    * `placeholder`: 사용자가 값을 입력하기 전에 보여주는 힌트 문구
    * `required`: 폼 제출 전 반드시 입력해야 하는 필수 항목으로 지정
    * `pattern`: 정규표현식(Regex, 예: `010-[0-9]{4}-[0-9]{4}`)으로 입력 형식을 검사
* **`<button>`**: 클릭 가능한 버튼을 만듭니다. `<form>` 내부에서 `type="submit"`(기본값)으로 설정하면 입력한 폼 데이터를 서버로 제출함.

```html
<form action="https://httpbin.org/post" method="post">
    <label for="user-email">이메일</label>
    <input id="user-email" type="email" name="email" placeholder="ex@example.com" required>
    <button type="submit">메일 발송</button>
</form>
```

## 7. 레이아웃 분할 및 시맨틱(Semantic) 태그

요소들을 그룹화하여 CSS 스타일과 레이아웃을 적용하거나, 문서 구조에 명확한 의미를 부여할 때 사용가능.

* **비시맨틱 컨테이너 태그 (`<div>`, `<span>`)**
  * **`<div>` (Division)**: 특별한 의미 없이 여러 요소를 묶어 레이아웃을 나눌 때 사용하는 대표적인 **블록 레벨(Block-level)** 태그입니다 (가로 한 줄 전체 차지).
  * **`<span>`**: 문장 내 일부 텍스트나 아이콘 등 필요한 영역만 묶어 스타일을 줄 때 사용하는 **인라인(Inline)** 태그 (내용 크기만큼만 공간 차지).
* **시맨틱(Semantic) 구조 태그**: 태그 이름 자체에 영역의 역할과 의미를 담아 가독성과 검색엔진 최적화(SEO)를 높이는 태그.
  * **`<header>`**: 페이지나 섹션의 상단 머리말 영역 (이름, 로고, 직무 타이틀 등)
  * **`<nav>`**: 다른 페이지나 영역으로 이동하는 네비게이션 메뉴 바 영역 (`navbar`)
  * **`<main>`**: 문서의 가장 핵심이 되는 본문 콘텐츠 영역
  * **`<section>`**: 본문 내에서 주제별로 구분되는 독립적인 구획 영역 (자기소개, 기술 스택, 학력 등)
  * **`<footer>`**: 페이지 하단의 저작권(Copyright), 작성자 연락처 등을 담는 바닥글 영역

## 8. 공통 핵심 글로벌 속성 (`id` vs `class`)

모든 HTML 태그에 공통으로 부여하여 CSS 스타일링이나 요소 식별에 활용하는 속성.

* **`id` 속성**: 문서 전체에서 **단 하나의 요소에만 고유하게 부여**하는 식별자 (중복 사용 불가). CSS에서는 `#아이디명`으로 선택.
  * 예: `<div id="contents">`, `<a id="github">`
* **`class` 속성**: **여러 요소에 공통된 스타일을 반복 적용**하기 위해 묶어주는 그룹 이름입니다 (중복 사용 및 다중 클래스 지정 가능). CSS에서는 `.클래스명`으로 선택.
  * 예: `<div class="box">`, `<section class="resume-section">`
