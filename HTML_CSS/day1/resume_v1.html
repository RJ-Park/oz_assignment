개체 번호: No.0401
개체 소개: 호기심을 연료로 삼아 개발을 배우고 있는 학습형 생명체.
주요 출몰지: GitHub

1. 서식 환경 및 기본 습성

  • 서식지: 집 책상 앞, 모니터 주변
  • 서식지 환경: 쾌적한 온도와 종종 안 터지는 와이파이가 있으며 고양이 두 마리가 늘어져 있는 곳
  • 특성: 새로 배운 내용은 직접 코드로 쳐보고 헤매며 머리 싸맴
  • 특성 참고 사항: 코딩 중 인상을 쓰고 있어도 화난 것이 아니라 집중한 상태임
  • 취미: 맛있는 음식 먹기, 음악 감상, 배운 내용 정리하기
  • 싫어하는 것: 원인 모를 에러 메시지, 저장 안 하고 꺼진 화면, 공복 상태

2. 영양 공급 가이드

  1. 주식: 든든한 집밥과 친절한 강의 교안
  2. 급여량: 하루 세 끼 규칙적인 식사 + 일일 코딩 복습
  3. 부식: 시원한 커피(또는 음료)와 달콤한 간식
  4. 공급 시 주의 사항: 당이 떨어지면 오타가 급증하므로 제때 간식을 공급할 것

3. 상세 능력치 및 특이사항

항목 구분 상세 내용
언어 능력 Python, HTML, CSS 현재 학습 중
기타 사항 성장 조건 칭찬과 격려(효과:학습 소폭 상승)
특이사항 2026.10 ~ 현재 OZ코딩스쿨 헬스케어 부트캠프에서 학습 중
