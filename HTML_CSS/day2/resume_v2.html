Introduce (개체 소개 및 서식 습성)

호기심을 연료로 삼아 개발을 배우고 있는 학습모드 인간 생명체입니다. 새로 배운 내용은 직접 코드로 쳐보고 헤매며 머리를 싸매는 습성이 있습니다.

서식 환경 및 기본 습성 상시 관찰됨
주요 서식지 집 책상 앞, 모니터 주변
  • 서식지 환경: 쾌적한 온도와 종종 안 터지는 와이파이가 있으며 고양이 두 마리가 늘어져 있는 곳
  • 특성: 새로 배운 내용은 직접 코드로 쳐보고 헤매며 머리 싸맴
  • 특성 참고 사항: 코딩 중 인상을 쓰고 있어도 화난 것이 아니라 집중한 상태임

Preferences & Languages (기호 및 능력)

FAVORITE / HOBBY (취미)

맛있는 음식 먹기 음악 감상 멍때리며 코드 보기

DISLIKE (싫어하는 것)

원인 모를 에러 메시지 저장 안 하고 꺼진 화면 공복 상태

Skill & Certification (능력 및 자격증)

Python (연습 중) HTML (연습 중) CSS (연습 중) 1급 응급구조사

Feeding Guide (영양 공급 가이드)

일일 급여 및 관리 수칙 1일 3식 + 간식 필수
  1. 주식: 든든한 집밥과 친절한 강의 교안
  2. 급여량: 하루 세 끼 규칙적인 식사 + 일일 코딩 복습
  3. 부식: 시원한 커피(또는 음료)와 달콤한 간식
  4. 공급 시 주의 사항: 당이 떨어지면 오타가 급증하므로 제때 간식을 공급할 것
