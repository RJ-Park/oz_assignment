# HTML / CSS 2일차 핵심 개념 정리 (`CSS.md`)

OZ코딩스쿨 HTML/CSS 2일차 수업 및 실습을 통해 학습한 CSS의 개념, 적용 방식, 선택자, 텍스트 및 박스 모델(Box Model) 속성 등을 정리한 문서입니다.

## 1. CSS란? (Cascading Style Sheets)

* **정의**: HTML로 작성된 웹 문서의 구조(뼈대) 위에 **색상, 글꼴, 크기, 여백, 정교한 레이아웃, 반응형 디자인 등 시각적 표현(스타일)을 입히는 스타일 시트 언어**입니다.
* **Cascading(계단식·폭포수)의 의미**: 상위 요소에 적용된 스타일이 하위 요소로 자연스럽게 상속되거나, 하나의 요소에 여러 스타일 규칙이 동시에 적용될 때 **우선순위(명시도, 선언 위치 등)**에 따라 위에서 아래로 흐르듯 최종 스타일이 결정된다는 의미를 담고 있습니다.

## 2. CSS를 적용하는 3가지 방식 비교 (`Inline` / `Internal` / `External`)

HTML 문서에 CSS 스타일을 적용하는 방법은 작성 위치에 따라 다음 3가지로 나뉩니다.

| 구분 | 적용 방법 및 예시 코드 | 특징 및 장단점 |
| :--- | :--- | :--- |
| **1. Inline CSS**<br>(인라인 스타일) | HTML 태그 내부의 `style` 속성에 직접 작성<br>`<h1 style="color: blue;">제목</h1>` | - 특정 태그 하나에만 즉각적으로 스타일을 적용할 때 편리함<br>- 우선순위가 가장 높지만, HTML 구조와 스타일 코드가 섞여 재사용과 유지보수가 어려움 |
| **2. Internal CSS**<br>(내부 스타일시트) | HTML 문서 `<head>` 내부에 `<style>` 태그를 만들어 작성<br>`<head><style> h1 { color: blue; } </style></head>` | - 별도의 파일 없이 단일 HTML 문서 안에서 스타일을 한곳에 모아 관리 가능<br>- 여러 HTML 페이지에서 동일한 디자인을 공유하기에는 비효율적임 |
| **3. External CSS**<br>(외부 스타일시트) | 독립된 `.css` 파일(`resume_style.css`)을 생성한 뒤 `<head>`에 `<link>` 태그로 연결<br>`<link rel="stylesheet" href="./resume_style.css">` | - **실무 표준 및 2일차 과제 필수 방식**<br>- HTML(구조)과 CSS(시각적 표현)를 완전히 분리하여 코드 가독성, 재사용성, 유지보수성이 가장 뛰어남 |

## 3. CSS Selector (선택자)

HTML 문서 내의 수많은 요소 중 **스타일을 적용할 대상을 정확히 지정하는 규칙**입니다.

1. **전체 선택자 (`*`)**
   * 문서 내의 모든 HTML 요소를 한꺼번에 선택합니다. 주로 브라우저 기본 여백 초기화나 `box-sizing: border-box;` 설정에 사용합니다.
   ```css
   * {
       box-sizing: border-box;
   }
   ```
2. **태그(요소) 선택자 (`Tag Selector`)**
   * `body`, `main`, `h2`, `p` 등 특정 HTML 태그 이름을 가진 모든 요소를 선택합니다.
   ```css
   body {
       background-color: #f9f9f9;
   }
   ```
3. **클래스 선택자 (`.class`)**
   * 마침표(`.`) 뒤에 클래스 이름을 붙여 표기하며, `class="skill-tag"`처럼 동일한 클래스를 가진 **여러 요소에 공통 스타일을 반복 적용**할 때 사용합니다. 한 요소에 여러 클래스를 띄어쓰기로 동시에 부여할 수도 있습니다.
   ```css
   .skill-tag {
       border-radius: 20px;
   }
   ```
4. **아이디 선택자 (`#id`)**
   * 샵(`#`) 기호 뒤에 아이디 이름을 붙여 표기하며, `id="resume-header"`처럼 **문서 내에서 단 하나뿐인 고유한 영역**을 선택할 때 사용합니다.
   ```css
   #resume-header {
       border-bottom: 2px solid #333;
   }
   ```
5. **복합(결합) 선택자**
   * **하위(후손) 선택자 (공백)**: 특정 요소 내부에 있는 모든 하위 요소를 선택합니다 (예: `main h2`, `.sidebar-menu li a`).
   * **자식 선택자 (`>`)**: 특정 요소의 바로 한 단계 아래 직계 자식 요소만 선택합니다 (예: `ul > li`).
6. **가상 클래스 선택자 (`:hover`, `:last-child` 등)**
   * 요소의 특정 상태나 위치에 따라 스타일을 적용합니다.
   * `:hover`: 마우스 커서를 요소 위에 올렸을 때 반응하는 스타일을 지정합니다 (예: `a:hover { color: #007bff; }`).
   * `:last-child`: 형제 요소 중 가장 마지막 요소만 선택합니다.

> **선택자 우선순위(명시도) 요약**:
> `Inline style` > `#id 선택자` > `.class / :가상클래스 선택자` > `태그 선택자` > `* 전체 선택자` (동일한 우선순위일 때는 **나중에 작성된 규칙**이 적용됨)

## 4. `style` 속성과 CSS 기본 문법 구조

* **HTML의 `style` 속성**: HTML 요소에 직접 인라인 방식으로 CSS 선언을 넣을 때 사용하는 글로벌 속성입니다.
  ```html
  <p style="font-size: 16px; font-weight: bold;">강조 문구</p>
  ```
* **CSS 선언 블록 구조**: 스타일시트 파일 안에서는 **선택자(Selector)** 뒤에 중괄호(`{ }`)를 열고 **`속성(Property): 값(Value);`** 쌍으로 작성하며, 각 선언의 끝에는 세미콜론(`;`)을 붙입니다.

## 5. Text 관련 주요 속성

웹 페이지의 타이포그래피(글자 크기, 굵기, 정렬, 색상, 간격 등)를 조절하는 핵심 속성입니다.

| 속성명 | 역할 및 설명 | 사용 예시 |
| :--- | :--- | :--- |
| **`font-family`** | 글꼴(폰트)을 지정하며, 앞의 폰트가 없을 때를 대비해 대체 폰트(`sans-serif` 등)를 콤마(`,`)로 나열합니다. | `font-family: 'Pretendard', sans-serif;` |
| **`font-size`** | 글자의 크기를 지정합니다 (`px` 절대 단위 또는 `rem`, `em` 상대 단위 활용). | `font-size: 1.5em;` |
| **`font-weight`** | 글자의 두께(굵기)를 지정합니다 (`normal`, `bold` 또는 `100`~`900` 사이의 수치). | `font-weight: 700;` |
| **`text-align`** | 블록 내부 텍스트의 가로 정렬 방향을 지정합니다 (`left`, `center`, `right`, `justify`). | `text-align: left;` |
| **`color`** | 글자의 색상을 지정합니다 (HEX 코드 `#333`, `rgb()`, 색상 키워드 등). | `color: #333333;` |
| **`line-height`** | 문단의 줄 간격(행간)을 조절하여 가독성을 높입니다. | `line-height: 1.6;` |
| **`text-decoration`** | 텍스트의 밑줄 등을 제어합니다 (`<a>` 링크 밑줄 제거 시 `none`, 표시할 때 `underline`). | `text-decoration: none;` |
| **`letter-spacing`** | 글자와 글자 사이의 간격(자간)을 조절합니다. | `letter-spacing: 1px;` |

## 6. Box Model (박스 모델)

HTML의 모든 요소는 사각형 박스 형태로 렌더링되며, 안쪽 중심부터 바깥쪽 순서로 **Content → Padding → Border → Margin**의 4단계 구조로 이루어집니다.

```text
+---------------------------------------------------+
|                   Margin (바깥 여백)                |
|   +-------------------------------------------+   |
|   |               Border (테두리)              |   |
|   |   +-----------------------------------+   |   |
|   |   |          Padding (안쪽 여백)        |   |   |
|   |   |   +---------------------------+   |   |   |
|   |   |   |   Content (width/height)  |   |   |   |
|   |   |   +---------------------------+   |   |   |
|   |   +-----------------------------------+   |   |
|   +-------------------------------------------+   |
+---------------------------------------------------+
```

* **`content` (`width`, `height`)**: 텍스트나 이미지 등 실제 알맹이가 들어가는 영역입니다. 기본적으로 `width`(너비)와 `height`(높이) 속성은 이 영역의 크기를 조절합니다 (`max-width`, `min-height` 등으로 최대/최소 크기 제한 가능).
* **`padding` (안쪽 여백)**: `content` 영역과 `border`(테두리) 사이의 내부 여유 공간입니다. 요소의 배경색(`background-color`)이 채워지는 영역입니다 (예: `padding: 40px;`).
* **`border` (테두리)**: 요소의 경계를 감싸는 선입니다. `border: 1px solid #eee;`처럼 **두께 · 선 스타일(`solid`, `dashed`) · 색상** 순으로 작성하며, `border-radius` 속성을 함께 쓰면 모서리를 둥글게 만들 수 있습니다 (`50%` 지정 시 원형 이미지 표현).
* **`margin` (바깥 여백)**: 테두리(`border`) 바깥쪽의 공간으로, **주변의 다른 요소들과 거리를 띄울 때** 사용합니다. 블록 요소에 `width`(또는 `max-width`)를 주고 `margin: 40px auto;`처럼 좌우 값을 `auto`로 설정하면 화면 가로 중앙에 정렬됩니다.
* **`box-sizing` (박스 크기 계산 기준)**:
  * **`content-box` (기본값)**: 지정한 `width`가 순수 `content` 크기만 의미하므로, `padding`과 `border`를 추가할수록 전체 박스의 실제 크기가 커져 레이아웃 계산이 복잡해집니다.
  * **`border-box` (실무 표준)**: 지정한 `width`와 `height` 값 안에 **`content + padding + border`를 모두 포함**하여 계산합니다. 안쪽 여백이나 테두리를 추가해도 전체 박스 너비가 변하지 않아 레이아웃을 안정적으로 잡을 수 있습니다.

## 7. 레이아웃 정렬(Flexbox), 배치(Position), 반응형 미디어 쿼리(`@media`)

2일차 이력서 스타일링에 함께 활용된 핵심 레이아웃 속성입니다.

* **Flexbox (`display: flex`)**: 부모 컨테이너에 `display: flex;`를 선언하여 자식 아이템들을 가로(`row`)나 세로(`column`)로 손쉽게 배치합니다.
  * `justify-content: space-between;`: 양끝으로 아이템을 밀어 배분 (헤더의 텍스트와 프로필 사진, 경력의 회사명과 기간 정렬 등)
  * `align-items: center;`: 세로(교차축) 중앙 정렬
  * `flex-wrap: wrap; gap: 10px;`: 공간이 부족하면 다음 줄로 자연스럽게 넘어가게 하고 아이템 사이 간격을 일정하게 유지 (스킬 태그 뱃지 정렬)
* **Position (`position: fixed`)**: 스크롤을 내려도 뷰포트(화면)의 특정 좌표(`top: 0; left: 0;`)에 요소를 고정합니다 (좌측 사이드바 `.sidebar` 구현).
* **반응형 디자인 (`@media`)**: 접속 기기의 화면 너비에 맞춰 스타일을 다르게 적용하는 미디어 쿼리입니다.
  ```css
  @media (max-width: 768px) {
      /* 화면 너비가 768px 이하(태블릿/모바일)일 때 적용할 스타일 */
  }
  ```
